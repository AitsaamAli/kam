Complete Guide to ATL in Pakistan 2026 — FBR Active Taxpayer List Explained

May 29, 2026
Kamboh Associates

Pakistan mein tax system samajhne ke liye Active Taxpayer List (ATL) ko samajhna sabse pehli zaroorat hai. ATL FBR ki woh official list hai jo directly decide karti hai ke aap par normal tax rates lagengi ya double. Is complete guide mein hum ATL ke bare mein har zaroori cheez cover karenge — kya hai, kaise kaam karti hai, kya fayde hain, ATL surcharge kya hai, aur apni active status kaise maintain karein.

ATL Kya Hai — FBR Active Taxpayer List

FBR Active Taxpayer List (ATL) ek officially published digital list hai jis mein Pakistan ke un tamam registered taxpayers ke CNIC/NTN numbers hote hain jinhon ne apni annual income tax return FBR IRIS portal par file ki ho.

Yeh list FBR.gov.pk par publicly available hoti hai. Har Monday ko update hoti hai. Banks, registrars, government agencies — sab is list ko check karte hain taake pata chale ke aap filer hain ya non-filer — aur usi hisaab se withholding tax deduct karte hain.

Simple rule: ATL mein naam = filer = reduced tax rates. ATL mein naam nahi = non-filer = double ya zyada tax. Yeh farq har transaction par apply hota hai — banking se lekar property tak.

ATL Kab Update Hoti Hai?

ATL ki update schedule FBR ke mutabiq:

Har Monday — Weekly Update
FBR ATL har haftay Monday ko update karta hai. Iska matlab hai agar aap ne return file ki, to agle Monday tak aapka naam list mein aa sakta hai.
Return file karne ke 24-72 ghante mein ATL mein naam aa jata hai
March 1 — Annual ATL Surcharge Deadline
Har saal 1 March ko ATL surcharge pay karne ki last date hoti hai. Jo log late return file karte hain unhe ATL mein wapas aane ke liye surcharge pay karna hota hai.
Surcharge amount: Individual Rs.1,000, AOP Rs.10,000, Company Rs.20,000

ATL Mein Naam Kaise Aata Hai?

ATL mein naam aane ka ek hi tareeqa hai — income tax return file karna. Yeh process simple hai:

01
NTN Registration
iris.fbr.gov.pk par jayen, CNIC se NTN register karein. Individual ke liye NTN = CNIC number. Bilkul free hai.
15-20 minute ka kaam hai
02
Income Tax Return File Karein
IRIS mein login karein, Declaration section mein Income Tax Return select karein, apni income aur assets declare karein, aur submit karein.
Deadline: September 30 — har saal
03
ATL Update Ka Intezar Karein
Return file karne ke 24-72 ghante ke andar aapka CNIC number ATL mein aa jata hai. SMS karein 9966 par ya atl.fbr.gov.pk par check karein.
"Active" aaye to aap officially filer hain

ATL Surcharge Kya Hai? — Late Filers Ke Liye

Agar aap ne September 30 ki deadline miss kar di aur baad mein return file ki — to ATL mein wapas aane ke liye ATL surcharge pay karni padti hai. Yeh ek late payment fee hai:

ATL surcharge ek baar ki fee hai — yeh pay karne ke baad aapka naam wapas ATL mein aa jata hai. Lekin yeh sirf 1 March tak valid hoti hai. Iske baad phir naya tax year ki return file karni hoti hai. Yeh samajh lein ke Rs.1,000 surcharge ek baar ki property transaction par Rs.2-3 lakh ke nuksan se bohot kam hai.

Aksar Pooche Jane Wale Sawalat

Kya sirf NTN lene se ATL mein naam aa jata hai?
Nahi. NTN registration aur ATL mein naam ana do alag cheezein hain. ATL mein naam aane ke liye aapko har saal income tax return file karni zaroor hai. Sirf NTN lene se aap registered to hain lekin non-filer hain.
ATL mein naam kab aata hai return file karne ke baad?
Return file karne ke 24 se 72 ghante ke andar generally naam aa jata hai. ATL har Monday ko update hoti hai. Agar return file ki hai to agle Monday tak confirm ho jata hai. SMS 9966 par CNIC send karke check karein.
ATL surcharge kab lagti hai?
ATL surcharge un logon par lagti hai jo September 30 ki deadline ke baad return file karte hain. Surcharge pay karne ki last date 1 March hoti hai. Individual ke liye Rs.1,000, AOP ke liye Rs.10,000, company ke liye Rs.20,000. Surcharge pay karne ke baad naam wapas ATL mein aa jata hai.
Kya ATL check free hai?
Haan, bilkul free hai. Aap kisi ka bhi ATL status check kar sakte hain — SMS 9966 par CNIC send karein ya atl.fbr.gov.pk par check karein. Koi charge nahi.
Agar main saal mein ek baar return file karta hoon to kya saal bhar active filer rehta hoon?
Haan. Ek baar return file karne ke baad aap agle saal ki return ki deadline (September 30) tak active filer rehte hain. Is liye agle saal bhi time par return file karna zaroori hai — warna inactive ho jaoge.
Nil income hai — kya phir bhi ATL mein naam aa sakta hai?
Haan. Agar aapki koi taxable income nahi hai to aap "nil return" file kar sakte hain — zero income ki return. ATL mein naam aa jayega aur aapko sab filer benefits milenge. Kamboh Associates se nil return filing ke liye rabta karein.
