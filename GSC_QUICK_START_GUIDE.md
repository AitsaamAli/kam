## 🚨 COMMON ISSUES & FIXES

### Issue: "Domain verification failed"
**Fix:**
- Check DNS record was entered correctly (copy-paste from GSC)
- Wait 30 minutes (DNS propagation)
- Try alternate verification method (HTML file upload)

### Issue: "Sitemap contains errors"
**Fix:**
- Check sitemap.xml is valid XML (no special characters)
- Ensure all URLs start with https://
- Re-upload sitemap.xml to server
- Resubmit in GSC

### Issue: "0 URLs indexed after 1 week"
**Fix:**
- Check robots.txt doesn't block /blogs/
- Verify blogs are actually accessible (test URLs in browser)
- Check no 404 errors on blogs
- Manually request indexing via URL Inspection tool

### Issue: "Crawl errors appearing"
**Fix:**
- Click error in Coverage report
- See what Google couldn't access
- Usually due to:
  - Server misconfiguration (contact hosting)
  - robots.txt blocking (check and fix)
  - URL structure issues (fix sitemap)
