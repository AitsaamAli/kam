❄️ FIRST TIME SETUP - پہلی بار (یہ ایک بار کریں)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: CMD/PowerShell کھولیں
┌─────────────────────────────────────────────────────────────────────────────┐
│ Windows میں:                                                                │
│ • Win + R دبائیں                                                             │
│ • "cmd" لکھیں                                                                │
│ • Enter دبائیں                                                               │
│                                                                              │
│ OR:                                                                          │
│ • Start menu میں "Command Prompt" سرچ کریں                                   │
│ • اس پر کلک کریں                                                              │
└─────────────────────────────────────────────────────────────────────────────┘


STEP 2: اپنے فولڈر میں جائیں - یہ بالکل ویسے لکھیں:
┌─────────────────────────────────────────────────────────────────────────────┐
cd C:\Users\786\Desktop\kam
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 3: Git شروع کریں:
┌─────────────────────────────────────────────────────────────────────────────┐
git init
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 4: اپنا نام سیٹ کریں (مثال):
┌─────────────────────────────────────────────────────────────────────────────┐
git config user.name "Kamran Khan"
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 5: اپنی ای میل سیٹ کریں (مثال):
┌─────────────────────────────────────────────────────────────────────────────┐
git config user.email "kamran@gmail.com"
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 6: تمام فائلیں شامل کریں:
┌─────────────────────────────────────────────────────────────────────────────┐
git add .
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 7: Commit کریں:
┌─────────────────────────────────────────────────────────────────────────────┐
git commit -m "Initial commit"
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 8: GitHub کے ساتھ جوڑیں (اپنا username ڈالیں):
┌─────────────────────────────────────────────────────────────────────────────┐
git remote add origin https://github.com/YOUR_USERNAME/kam.git

مثال (اگر آپ کا username "kamran786" ہے):
git remote add origin https://github.com/kamran786/kam.git
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 9: Main branch بنائیں:
┌─────────────────────────────────────────────────────────────────────────────┐
git branch -M main
                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 10: GitHub پر پوش کریں:
┌─────────────────────────────────────────────────────────────────────────────┐
git push -u origin main

اگر لاگ ان کہے:
• اپنا GitHub username لکھیں
• اپنا GitHub password لکھیں
• Enter دبائیں

✅ تمام ہو گیا!
└─────────────────────────────────────────────────────────────────────────────┘

STEP 1: اپنے فولڈر میں جائیں:

STEP 2: نئے/تبدیل شدہ فائلیں شامل کریں:

                                                                    Enter دبائیں
└─────────────────────────────────────────────────────────────────────────────┘


STEP 3: Commit کریں (اپنا post کا نام):

⚠️ عام غلطیاں اور حل
═══════════════════════════════════════════════════════════════════════════════

❌ Error: "fatal: not a git repository"
🔧 حل:
   git init

❌ Error: "fatal: could not read Username"
🔧 حل: اپنا GitHub password بھریں (invisible لکھا جائے گا)

❌ Error: "fatal: The remote origin already exists"
🔧 حل:
   git remote remove origin
   git remote add origin https://github.com/YOUR_USERNAME/kam.git

❌ Error: "nothing to commit"
🔧 حل: کوئی فائل تبدیل نہیں کی۔ پہلے فائل میں تبدیلی کریں۔

❌ Blog post دکھائی نہیں دے رہا
🔧 حل:
   1. blogs.html میں post کا entry ہے یا نہیں چیک کریں
   2. Vercel dashboard میں deployment complete ہے یا نہیں چیک کریں
   3. 2-3 منٹ انتظار کریں
   4. براؤزر میں Ctrl+Shift+R دبائیں (hard refresh)
