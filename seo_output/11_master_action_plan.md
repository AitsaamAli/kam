## RED FLAGS TO WATCH FOR

| Red Flag | What It Means | What to Do |
|----------|--------------|------------|
| Manual Action in GSC | Google penalized the site | Read the notice, fix issue, submit reconsideration |
| Sudden traffic drop | Algorithm update or penalty | Check GSC, compare with update dates at moz.com/google-algorithm-change-history |
| Duplicate content warning | Copied or near-duplicate pages | Rewrite the duplicate page |
| Core Web Vitals "Poor" | Page too slow | Compress images, remove heavy JS |
| Toxic backlinks | Spam sites linking to you | Disavow via GSC (search: Google Disavow Tool) |
| Keyword cannibalization | 2 pages competing for same keyword | Merge or redirect the weaker one |
| GMB suspension | Profile policy violation | Review GMB guidelines, appeal suspension |
