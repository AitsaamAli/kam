WORKFLOW TO ADD A BLOG POST:
═══════════════════════════════════════════════════════════════════════════

1. OPEN blog-sample.html in text editor
2. SAVE AS your-post-title.html (e.g., tax-tips-2026.html)
3. EDIT the content:
   - Change <title>
   - Update meta description
   - Write your content
   - Update publish date
4. OPEN blogs.html
5. ADD entry to blogPosts array:
   {
     id: 'tax-tips-2026',
     title: 'Tax Tips for 2026',
     excerpt: 'Essential tax tips for businesses',
     category: 'Tax Planning',
     date: '2026-05-19',
     author: 'Kamboh Associates',
     readTime: '5 min read',
     icon: '📊'
   }
6. SAVE both files
7. COMMIT & PUSH:
   git add .
   git commit -m "Add blog: Tax Tips for 2026"
   git push

8. VERIFY:
   • Check Vercel dashboard
   • Wait 2 minutes for deployment
   • Visit website → Blog post is LIVE! ✨

SEO BEST PRACTICES:
═══════════════════════════════════════════════════════════════════════════

BEFORE PUBLISHING EACH POST:

Title (50-60 characters):
  ✓ "Essential Tax Deductions for 2026" (38 chars) ✓
  ✓ Keyword at start when possible
  ✗ Too long: "The Complete Comprehensive Guide to Understanding..."

Meta Description (150-160 characters):
  ✓ "Learn about valuable tax deductions for Pakistani businesses. Maximize 
    savings with proper planning strategies." (110 chars) ✓
  ✗ Too short: "Tax guide" (not descriptive)
  ✗ Too long: "Lorem ipsum dolor sit amet consectetur..."

Content:
  ✓ Minimum 300 words (recommended 800-1500)
  ✓ Use target keywords naturally
  ✓ Include numbered lists/bullets
  ✓ Add subheadings (H2, H3)
  ✓ Keep paragraphs short (3-4 sentences)
  ✓ Use bold for key terms
  ✓ Link to related posts

Links:
  ✓ Link to other blog posts
  ✓ Link to your services page
  ✓ Link to contact page
  ✓ Use descriptive anchor text

TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════

Problem: "fatal: not a git repository"
Solution: Run "git init" in your project folder

Problem: "fatal: could not read Username"
Solution: Use HTTPS instead of SSH, or set up GitHub token

Problem: Blog post not showing
Solution: 
  1. Check blogs.html has the entry
  2. Verify Vercel deployment completed
  3. Hard refresh browser (Ctrl+Shift+R)

Problem: Styling looks broken
Solution: Check file paths in CSS/HTML links

Problem: Can't push to GitHub
Solution: Check internet connection, verify GitHub token
