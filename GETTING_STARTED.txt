📊 HOW TO ADD BLOG POSTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Create HTML file
        Copy blog-sample.html → your-post-title.html
        Edit the content

STEP 2: Update blog listing
        Edit blogs.html
        Add post to blogPosts array:
     {
  id: 'income-tax-return-pakistan',
  title: 'Who Should File Income Tax Return in Pakistan?',
  excerpt: 'Complete guide for salaried persons, freelancers, and business owners in Pakistan.',
  category: 'Taxation',
  date: '2026-05-20',
  author: 'Kamboh Associates',
  readTime: '8 min read',
  icon: '📄',
  url: '/blog/income-tax-return-pakistan.html'
},

STEP 3: Deploy
        git add .
        git commit -m "Add blog: Your Title"
        git push
        
        → LIVE in 90 seconds! ✨
