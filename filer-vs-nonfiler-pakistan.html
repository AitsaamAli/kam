Filer vs Non-Filer in Pakistan 2026: Complete Tax Rate Comparison

May 29, 2026
Kamboh Associates
8 min read
Lahore, Pakistan

Pakistan mein filer aur non-filer ka farq sirf ek tax form nahi hai — yeh aapki jeb par directly asar karta hai. Har banking transaction, property ki kharid-o-farokht, gaari ki registration, aur dividend income par non-filer ko filer se 2x zyada tax dena parta hai. Is guide mein hum ne exact rates, real savings examples, aur filer banne ka complete tarika explain kiya hai.

Tax Filer Kaun Hota Hai Pakistan Mein?

FBR (Federal Board of Revenue) ki nazar mein ek tax filer woh shakhs hai jis ne apna National Tax Number (NTN) register karaya ho aur annual income tax return FBR ke IRIS portal par file kiya ho, aur uska naam FBR ki Active Taxpayer List (ATL) mein shamil ho.

ATL FBR ki official published list hai jo har saal update hoti hai. Jab aap tax return file karte hain, aapka CNIC number is list mein aa jata hai — aur tabhi aap legally "Active Filer" kehlaate hain aur tamam filer benefits milte hain.

Important: Sirf NTN lene se aap filer nahi bante. ATL mein naam aane ke liye aapko har saal income tax return file karna ZAROOR hai. Aap apna ATL status verify kar sakte hain atl.fbr.gov.pk par ya 9966 par apna CNIC SMS karke.

Non-Filer (Befiler) Kaun Hota Hai?

Non-filer woh shakhs hai jis ne ya to NTN register nahi karaya, ya NTN hai magar income tax return file nahi ki, ya return file ki magar ATL mein naam nahi aaya. Pakistan mein aise logon ko "befiler" bhi kaha jata hai.

Non-filer status sirf ek paper ka masla nahi — yeh aapko har saal lakho rupees ka nuksan karta hai banking, property, vehicles, aur investments par. FBR non-filers ke liye withholding tax rates 2x ya 4x zyada rakhti hai intentionally.

Filer Kaise Banein? Step-by-Step Guide 2026

Filer banna 2026 mein pehle se kaafi asaan ho gaya hai. Yeh 3 steps hain:

01
NTN Registration (FBR IRIS)
Pehle iris.fbr.gov.pk par jayen aur "Registration for Unregistered Person" par click karein. CNIC number, CNIC wali SIM ka number, aur email address chahiye hoga. NTN bilkul free milta hai.
Individual ka NTN number uska CNIC number hi hota hai
02
Income Tax Return File Karein
NTN milne ke baad IRIS mein login karein aur annual income tax return file karein. Apni salary slips, bank statements, aur property/assets ki details bharen. Return file karna hi ATL mein naam lane ka zariya hai.
FY 2025-26 return ki deadline: September 30, 2026
03
ATL Status Verify Karein
Return file hone ke 24-72 ghante baad apna ATL status check karein. SMS karein apna 13-digit CNIC number (bina dashes ke) 9966 par — ya check karein atl.fbr.gov.pk par.
Active likhta aaye to aap officially filer hain

Aksar Pooche Jane Wale Sawalat (FAQs)

Kya salaried person ko filer hona zaroori hai?
Haan, absolutely. Salaried persons ka income tax employer deduct karta hai, lekin FBR ki ATL mein naam aane ke liye aapko khud return file karni hoti hai. Bina return file kiye aap non-filer raheinge — aur har banking, property transaction par double tax lagega. Agar aapki annual salary Rs. 6 lakh se zyada hai to return file karna legally bhi zaroori hai.
NTN lene ke baad kitne din mein filer ban jata hoon?
NTN milna aur filer banana do alag cheezein hain. NTN milne ke baad aapko income tax return file karni hogi. Return file hone ke 24 se 72 ghante ke andar naam ATL mein aa jata hai. Kamboh Associates ke zariye pura process 24 ghante mein complete ho sakta hai.
Agar pehle se befiler hoon to kya kar sakta hoon?
Abhi bhi late nahi. FBR aapko previous years ki returns file karne ki ijazat deta hai — ise "late filing" kehte hain. Haan, kuch penalties lag sakti hain, lekin filer banne ke fayde in penalties se bohot zyada hain. Kamboh Associates aapki back-years ki returns bhi file kar sakti hai. WhatsApp karo: 0328-4675162.
Kya freelancers aur overseas Pakistanis ko bhi filer hona chahiye?
Bilkul. Freelancers jo Pakistan mein rehte hain aur foreign clients se paise receive karte hain unhe NTN lena aur return file karna zaroori hai. Foreign remittance par non-filer 4% tax deta hai vs filer 2%. Overseas Pakistanis ke liye bhi return filing beneficial hai — khaskar agar Pakistan mein property ya bank accounts hain.
Kya main khud return file kar sakta hoon ya professional ki zaroorat hai?
Technically aap khud IRIS portal par file kar sakte hain. Lekin IRIS portal complex hai — sahi forms, sahi amounts, aur wealth statement sahi bharna mushkil ho sakta hai.
