10 Sabse Common Income Tax Return Mistakes

01
Galat ya Incomplete Income Declaration
Sabse common ghalti — salary se zyada ya kam income show karna. Kuch log sirf basic salary likhtay hain, allowances (HRA, TA, medical) chhor dete hain. Dusre log rent income, freelance income, ya bank interest declare hi nahi karte. FBR ke paas aapke employer, bank, aur tax deductors se poori information hoti hai — koi bhi discrepancy turant flag hoti hai.
Fix: Apne employer se annual tax certificate (u/s 50) hasil karein. Sab income sources list karein — salary, rent, bank interest, dividends, freelance — sab. Hamesha complete income declare karein.
02
Wealth Statement Skip Karna Ya Galat Bharna
Wealth Statement return ka sabse important hissa hai — aur sabse zyada skip hota hai ya galat bhara jata hai. Aapki property, gaari, bank balance, investments, zewarat — sab kuch accurately declare karna zaroori hai. Agar wealth statement main gaps hain ya previous year se unexplained increase hai to FBR automatically notice bhejta hai.
Fix: Har asset ki current market value ya cost price accurately bharen. Property ke property tax records se value nikalen. Bank statements se balance confirm karein. Koi bhi asset hide mat karein — FBR ke paas cross-data hai.
03
Employer Ka Deducted Tax Claim Na Karna
Majority salaried employees yeh ghalti karte hain. Aapke employer ne poore saal aapki salary se withholding tax (WHT) kaat kar FBR ko jama kiya hai. Agar aap return mein yeh deducted tax claim nahi karte to aap refund ke haqdar hote hue bhi kuch nahi pate — ya phir double tax pay karne ki naubi aati hai.
Fix: Employer se "Tax Deduction Certificate" ya "Annual Salary Statement" (Section 50 certificate) hasil karein. Return mein "Tax Already Paid / Deducted" section mein yeh amount accurately darj karein.
04
Galat Tax Year Select Karna
Pakistan mein tax year July 1 se June 30 tak hota hai — July 2025 se June 2026 tak wali return "Tax Year 2026" kehlaati hai. Bohot log English calendar year ke hisaab se sochte hain (January-December) aur galat tax year select kar lete hain. Is se return galat year mein file ho jati hai aur aapka ATL status bhi properly update nahi hota.
Fix: Pakistan mein Tax Year = July se June. Tax Year 2026 = 1 July 2025 to 30 June 2026. IRIS mein return form open karte waqt tax year carefully select karein.
05
Eligible Deductions Claim Na Karna
FBR Pakistan mein kai legal tax deductions available hain jo log use hi nahi karte — kyunke unhe pata nahi hota. Zakat, pension contributions, life insurance premium, education tuition fee, donations to approved organizations, investment in Bahbood certificates — sab pe deductions available hain jo aapka final tax kam kar sakte hain.
Fix: Common deductions yaad rakhein: Zakat (u/s 60), pension (u/s 63), Behbood Certificates (u/s 62), life insurance (u/s 62), tuition fee (u/s 60C). Sab supporting documents ke sath claim karein.

06
Tax Return Filing Deadline Miss Karna
September 30 Pakistan mein income tax return filing ki last date hai — aur yeh fixed deadline hai. Deadline miss karne par FBR Rs.1,000 per month penalty + ATL surcharge (Rs.1,000 individual) lagate hain. Kuch log sochte hain "baad mein file kar lenge" — lekin iss delay ki wajah se unhein penalties aur double WHT dono bhugna parta hai.
Fix: September 30 ko calendar mein mark karein. August mein hi documents prepare shuru karein. Kamboh Associates yearly reminder aur filing service provide karta hai — ek baar register karein, har saal on time file hogi.
07
Nil Return Na Filing (Jab Income Zero Hो)
Kuch log kehte hain "meri income nahi hai to mujhe return nahi karni" — yeh ghalat soch hai. ATL mein naam rakhne ke liye aur filer status maintain karne ke liye NTN holders ko nil return bhi file karni zaroori hai. Nil return = zero income ki return = ATL benefits maintain rehen.
Fix: Agar is saal koi taxable income nahi bhi hai to bhi return file karein. Nil return mein sirf zero bharna hota hai — 10-minute ka kaam. Property/gaari wale afraad ke liye yeh aur bhi zaroori hai.
08
Bank WHT aur Advance Tax Claim Na Karna
Bank se cash withdrawal, IBFT, cheque transactions par jo withholding tax kati gayi hai — woh aapke income tax mein adjustable hai. Isi tarah advance income tax (agar kisi ne advance pay kiya hai) — yeh sab return mein properly claim karna hota hai. Nahi kiya to yeh paise FBR ke paas reht jaate hain — aapko refund nahi milta.
Fix: Apne bank se annual WHT certificate hasil karein. Return mein "Advance Tax" aur "Withholding Tax" sections mein sab accurately fill karein. Agar refund banta hai to bank account details also fill karein.
09
Galat Taxpayer Category Select Karna
IRIS mein return file karte waqt aapko apni taxpayer category select karni hoti hai — Salaried, Business Individual, AOP, Company, etc. Galat category select karne se wrong tax slabs apply hote hain. Ek salaried person ko "Business Individual" form mein file karna alag results dega aur potentially FBR flag kar sakta hai.
Fix: Salaried person? "114(1) Salaried" form select karein. Business income? "114(1) Business Individual." Agar multiple sources hain to consult karein — Kamboh Associates se free advice lo ke aapke liye kaunsa form sahi hai.
10
Return Submit Karne Ka Proof Save Na Karna
IRIS par return submit hone ke baad ek acknowledgment number aur confirmation aata hai. Bahut log ise save nahi karte. Agar baad mein FBR dispute ya audit ka samna ho, to yeh acknowledgment proof hai ke aap ne time par return file ki thi. Bina proof ke aap apni filing date prove nahi kar saktey.
Fix: Return submit hone ke baad IRIS se acknowledgment/receipt PDF download aur save karein. Email par bhi bhej dein khud ko. Kamboh Associates har client ko filed return ki copy aur acknowledgment provide karta hai.

Lekin revised return mein tax barhta bhi hai — is liye pehle bar hi sahi karna better hai. Kamboh Associates revised return filing mein help karta hai.
FBR notice aaye to kya karna chahiye?
FBR notice aana scary lagta hai lekin ghabrayen nahi. Notice mein likha hota hai ke kis cheez ki information chahiye. Notice ki deadline ke andar properly respond karein — supporting documents ke sath. Agar return mein actual ghalti thi to revised return file karein.
