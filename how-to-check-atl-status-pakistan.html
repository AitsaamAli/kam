How to Check ATL Status Online in Pakistan 2026 — 3 Easy Methods

May 29, 2026
Kamboh Associates
5 min read
Lahore, Pakistan

Pakistan mein apna ATL status check karna ek 2-minute kaam hai — aur yeh bohot zaroori hai. Bank, property dealer, gaari registrar — sab ATL check karte hain. Agar aapko khud nahi pata ke aap filer hain ya nahi, to yeh guide aapko sikhayega ke 3 alag tareeqon se ATL status check karna kitna asaan hai. Sab methods bilkul free hain.

TL;DR

Check your ATL status instantly by sending your CNIC to 9966 via SMS. If not on ATL, file your income tax return to get active within 2-3 days.

ATL Status Check Karna Kyun Zaroori Hai?

ATL status check karna in situations mein zaroor karna chahiye:

Property khareedne se pehle
Gaari register karne se pehle
Bank account khulwane se pehle
Government tender apply karne se pehle
Return file karne ke baad confirm karne ke liye
Kisi bhi doosre shakhs ka status check karne ke liye

Koi bhi check kar sakta hai: ATL status check karne ke liye koi registration ya login ki zaroorat nahi. Kisi bhi CNIC ka status check kar sakte hain — bilkul free. Aap seller ka bhi status check kar sakte hain property deal se pehle.

Method 1 — SMS 9966 (Sabse Asan Tareeqa)

SMS method sabse fast aur convenient hai — bina internet ke bhi kaam karta hai. Yeh tareeqa use karein:

Method 1 — SMS
9966 par SMS bhejein
Apna 13-digit CNIC number (dashes ke bina) SMS karein number 9966 par. Telenor, Jazz, Zong, Ufone — kisi bhi network se kaam karta hai.
1
Messages app kholein aur new message likhein
2
Message mein sirf apna 13-digit CNIC likhen — dashes ke bina (e.g., 3520112345678)
3
SMS number 9966 par send karein
4
Kuch seconds mein FBR ka automated reply aayega
"Active" — Aap filer hain ✓
"Not in ATL" — Aap non-filer hain

SMS method ka fayda: Internet ki zaroorat nahi. Roaming par bhi kaam karta hai. Instant reply milta hai. Kisi ka bhi CNIC send kar sakte hain check ke liye.

Method 2 — FBR ATL Website (atl.fbr.gov.pk)

Online portal se check karna bhi bilkul free aur instant hai. Aap ek baar mein multiple CNICs check kar sakte hain:

Method 2 — Website
atl.fbr.gov.pk par jayen
atl.fbr.gov.pk FBR ka official ATL verification portal hai. Koi login nahi chahiye — seedha CNIC enter karein aur result paye.
1
Browser mein atl.fbr.gov.pk open karein
2
Search box mein apna 13-digit CNIC number enter karein
3
Captcha complete karein (agar show ho)
4
"Search" button click karein — fori result aayega
Green Result — ATL mein Active
No Result / Inactive — Non-filer

Method 3 — FBR IRIS Portal (Registered Users Ke Liye)

Agar aap ne NTN registration ki hai aur IRIS par account hai, to IRIS dashboard se directly check kar sakte hain:

Method 3 — IRIS Portal
iris.fbr.gov.pk mein login karein
iris.fbr.gov.pk par login karne ke baad aapka ATL status dashboard par directly visible hota hai.
1
iris.fbr.gov.pk par jayen aur apne CNIC/NTN aur password se login karein
2
Dashboard par "My Profile" ya "Taxpayer Information" section mein jayen
3
ATL Status field check karein — Active ya Inactive show hoga
4
Agar inactive hai to Declaration > Income Tax Return file karein
Active — All filer benefits available
Inactive — Return file karein

ATL Status Inactive Aaye To Kya Karein?

ATL inactive aane ka matlab hai ke ya to aap ne return file nahi ki ya return file ki lekin ATL update hona baaki hai. Yeh karo:

1
NTN hai magar return file nahi ki?
IRIS par login karein aur income tax return file karein. 24-72 ghante mein naam ATL mein aa jayega.
2
NTN bhi nahi hai?
Pehle NTN register karein — IRIS par bilkul free. Phir return file karein. Hamare NTN Registration Guide mein complete process hai.
3
Return file ki thi magar naam nahi aaya?
Return file karne ke baad ATL update Monday ko hoti hai. 3-5 din wait karein. Agar phir bhi na aye to IRIS submission check karein ya Kamboh Associates se rabta karein.
4
Deadline miss ho gayi?
ATL Surcharge (Rs.1,000 individual) pay karein aur late return file karein. 1 March deadline se pehle — naam wapas ATL mein aa jayega.

Kuch log ek baar ATL inactive hone ke baad ghabrake property ya gaari transactions rok dete hain — yeh galat hai. ATL inactive hai to wapas active hona easy hai — return file karo ya surcharge pay karo. Kamboh Associates se 24 ghante mein yeh resolve ho jata hai.

Aksar Pooche Jane Wale Sawalat

ATL check karna free hai?
Haan, bilkul free hai. SMS method mein standard SMS charges lag sakte hain lekin atl.fbr.gov.pk par check karna completely free hai — koi registration ya login nahi chahiye.
Kya main kisi doosre ki CNIC ka ATL check kar sakta hoon?
Haan, ATL publicly accessible hai. Aap kisi bhi CNIC ka status check kar sakte hain — chaahe aap seller hain, buyer hain, ya business partner. Yeh information confidential nahi hai — FBR ne ise deliberately public rakha hai.
Return file karne ke baad ATL update kitne din mein hoti hai?
Generally 24-72 ghante. Lekin FBR ATL har Monday ko officially update karti hai. Agar aap ne shaam ko return file ki to agle ek-do din mein SMS 9966 se check karein — Active aana chahiye.
IRIS portal par login ka password bhool gaya — kya karo?
IRIS portal par "Forgot Password" option hai. CNIC aur registered mobile number se OTP verify karke password reset kar sakte hain. Agar yeh bhi nahi ho to FBR helpline 0800-00227 par call karein ya Kamboh Associates se madad lein.
ATL check mein "Not in ATL" aaya — kya aur koi raasta hai?
"Not in ATL" result ka matlab hai aap non-filer hain. Wapas active hone ke liye income tax return file karni hogi ya late filing ATL surcharge pay karni hogi. Kamboh Associates yeh process aapke liye handle karta hai — WhatsApp karein 0328-4675162.
