═══════════════════════════════════════════════════════════════════════════════
                    STEP 1️⃣: GITHUB ACCOUNT بنائیں (5 منٹ)
═══════════════════════════════════════════════════════════════════════════════

1. اپنا براؤزر کھولیں (Chrome, Edge, Firefox کوئی بھی)

2. یہ URL لکھیں یا کلک کریں:
   👉 https://github.com/signup

3. یہ معلومات بھریں:
   📧 Email: اپنی ای میل ڈالیں (مثلاً: kamran.khan@gmail.com)
   
   🔐 Password: ایک مضبوط پاس ورڈ بنائیں
   (مثلاً: MyBlog2026@123)
   
   👤 Username: کوئی نام منتخب کریں
   (مثلاً: kamran786 یا kamboh-associates)
   
   ✅ "Create account" بٹن دبائیں

4. آپ کی ای میل میں ایک سیاق ہوگی
   → Email کھولیں
   → "Verify email address" لنک دبائیں
   
5. بس! GitHub اکاؤنٹ تیار ہے! ✅


═══════════════════════════════════════════════════════════════════════════════
                    STEP 2️⃣: GitHub پر Repository بنائیں (5 منٹ)
═══════════════════════════════════════════════════════════════════════════════

1. GitHub میں لاگ ان کریں

2. صفحہ کے اوپر دائیں طرف "+" آئیکن دیکھیں
   → اس پر کلک کریں
   → "New repository" منتخب کریں

3. یہ تفصیلات بھریں:

   Repository name: kam
   
   Description: Kamboh Associates - Tax & Regulatory Services
   
   Visibility: PUBLIC (عوامی - یہ ضروری ہے!)
   
   ✅ "Create repository" دبائیں

4. آپ کو یہ URL ملے گا (یاد رکھیں):
   
   👉 https://github.com/YOUR_USERNAME/kam.git
   
   (YOUR_USERNAME کی جگہ اپنا نام ڈالیں)


═══════════════════════════════════════════════════════════════════════════════
                    STEP 3️⃣: Git CMD میں Setup کریں (5 منٹ)
═══════════════════════════════════════════════════════════════════════════════

🔴 یہ بہت ضروری ہے! احتیاط سے فالو کریں۔

1️⃣ CMD/PowerShell کھولیں:
   
   Windows میں:
   • Win + R دبائیں
   • "cmd" لکھیں
   • Enter دبائیں

2️⃣ اپنے فولڈر میں جائیں:
   
   یہ کمانڈ لکھیں (کاپی-پیسٹ کریں):
   
   cd C:\Users\786\Desktop\kam
   
   ✅ Enter دبائیں

3️⃣ Git شروع کریں:
   
   git init
   
   ✅ Enter دبائیں

4️⃣ اپنا نام اور ای میل سیٹ کریں:
   
   git config user.name "Your Full Name"
   
   مثال:
   git config user.name "Kamran Khan"
   
   ✅ Enter دبائیں
   
   ---
   
   git config user.email "your.email@gmail.com"
   
   مثال:
   git config user.email "kamran@gmail.com"
   
   ✅ Enter دبائیں

5️⃣ تمام فائلیں شامل کریں:
   
   git add .
   
   ✅ Enter دبائیں

6️⃣ پہلا Commit کریں:
   
   git commit -m "Initial commit: Blog system setup"
   
   ✅ Enter دبائیں

7️⃣ GitHub کے ساتھ جوڑیں:
   
   git remote add origin https://github.com/YOUR_USERNAME/kam.git
   
   ❌ YOUR_USERNAME کو اپنے GitHub username سے بدلیں!
   
   مثال:
   git remote add origin https://github.com/kamran786/kam.git
   
   ✅ Enter دبائیں

8️⃣ Main branch کا نام بدلیں:
   
   git branch -M main
   
   ✅ Enter دبائیں

9️⃣ GitHub پر پوش کریں:
   
   git push -u origin main
   
   ✅ Enter دبائیں

🟢 اگر کوئی لاگ ان والا سوال ہو تو:
   • اپنا GitHub username لکھیں
   • اپنا password لکھیں
   
   ✅ تمام کمانڈز کے بعد "Done" جیسا پیغام آئے گا


═══════════════════════════════════════════════════════════════════════════════
                    STEP 4️⃣: Vercel پر Deploy کریں (5 منٹ)
═══════════════════════════════════════════════════════════════════════════════

1. یہ URL کھولیں:
   👉 https://vercel.com

2. "Sign up" دبائیں

3. "Continue with GitHub" منتخب کریں

4. GitHub سے Authorize کریں
   (Vercel کو اپنے repositories دیکھنے کی اجازت دیں)

5. اپنے "kam" repository کو تلاش کریں
   → اس پر کلک کریں

6. Import کریں

7. Settings میں کوئی تبدیلی نہ کریں - سب ڈیفالٹ ہے

8. "Deploy" بٹن دبائیں

9. 1-2 منٹ انتظار کریں...

🟢 تمام ہو گیا! آپ کو یہ URL ملے گا:
   👉 https://kam-xxx.vercel.app
   
   اس پر کلک کریں اور اپنی سائٹ دیکھیں! 🎉


═══════════════════════════════════════════════════════════════════════════════
                    STEP 5️⃣: نیا Blog Post شامل کریں (1 گھنٹہ)
═══════════════════════════════════════════════════════════════════════════════

اب آپ کا پہلا blog post بنائیں!

1️⃣ "blog-sample.html" فائل کھولیں
   (اپنے kam فولڈر میں ہے)

2️⃣ یہ جگہوں کو اپنے ڈیٹا سے بدلیں:

   <title>YOUR TITLE - Kamboh Associates</title>
   
   مثال:
   <title>Tax Deductions 2026 - Kamboh Associates</title>
   
   ---
   
   <meta name="description" content="YOUR DESCRIPTION"/>
   
   مثال:
   <meta name="description" content="Learn essential tax deductions for Pakistani businesses"/>
   
   ---
   
   <h1 class="post-title">YOUR BLOG TITLE</h1>
   
   ---
   
   <div class="post-content">
     <p>یہاں اپنا ڈیٹا لکھیں</p>
   </div>

3️⃣ فائل کو Save کریں (Ctrl+S)
   اسے اس نام سے Save کریں:
   
   tax-deductions-2026.html
   
   (یا اپنا نام)

4️⃣ "blogs.html" فائل کھولیں

5️⃣ یہ لائن تلاش کریں:
   
   const blogPosts = [
   
6️⃣ اس میں یہ شامل کریں:

   {
     id: 'tax-deductions-2026',
     title: 'Essential Tax Deductions for 2026',
     excerpt: 'Learn about valuable tax deductions for businesses',
     category: 'Tax Planning',
     date: '2026-05-19',
     author: 'Kamboh Associates',
     readTime: '5 min read',
     icon: '📊'
   },

7️⃣ Save کریں (Ctrl+S)
