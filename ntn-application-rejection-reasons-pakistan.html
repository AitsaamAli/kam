8 Common Reasons NTN Applications Get Rejected in Pakistan — And Exactly How to Fix Each One

May 29, 2026
Kamboh Associates
8 min read
Lahore, Pakistan

NTN application submit ki, OTP ka wait kiya, aur phir — error ya rejection. Yeh experience frustrating hota hai, especially jab aapko jaldi hoti hai. Hamare paas har hafte aisi calls aati hain. Achhi baat yeh hai ke NTN rejection almost always fixable hai — agar sahi wajah pata ho. Is guide mein top 8 rejection reasons aur unka exact solution cover karte hain.

Top 8 NTN Application Rejection Reasons — Aur Unke Fixes

1
Mobile Number CNIC Se Registered Nahi
FBR IRIS OTP registered mobile par bhejta hai. Agar aapka mobile number NADRA records mein aapke CNIC se linked nahi — OTP nahi aata. Aur bina OTP ke verification nahi ho sakti. Yeh sab se zyada common rejection reason hai — especially jo log kisi doosre ke naam wali SIM use karte hain.
Fix: Apne CNIC ke saath kisi bhi mobile franchise (Jazz/Ufone/Zong/Telenor) par jayein. Biometric verification karwayein aur SIM ko apne CNIC se link karwayein. 24 ghante mein update ho jata hai.
2
CNIC Expired Hai
FBR system valid CNIC hi accept karta hai. Agar aapka CNIC expire ho chuka hai — system registration allow nahi karega. Bahut log yeh zaroorat ignore karte hain kyunki daily kaam mein CNIC expiry usually issue nahi banta.
Fix: NADRA office ya Citizen Portal se CNIC renew karwayein. Urgent processing Rs. 500 extra mein 3 working days mein hoti hai. Regular fee mein 15–30 days lag sakte hain.
3
Duplicate NTN — Pehle Se Exist Karta Hai
CNIC se pehle kisi ne NTN register karwaya tha — shayad koi purana consultant, ya aapne khud kisi aur device se try kiya — aur aapko yaad nahi. System existing NTN par dobara registration nahi karne deta. Yeh mostly bhoolne wala scenario hai, galti ka nahi.
Fix: Pehle check karein: atl.fbr.gov.pk par CNIC enter karein — agar naam show hota hai, NTN pehle se hai. FBR helpline 051-111-772-772 par call karein aur existing credentials recover karein.
4
Wrong Jurisdiction Code Select Kiya
Business NTN registration mein RTO (Regional Tax Office) select karna hota hai. Lahore, Karachi, Islamabad, Faisalabad — sab ke liye alag RTO codes hain. Wrong jurisdiction select karne par application reject hoti hai ya processing delay hoti hai indefinitely.
Fix: Apne business address ke city ke mutabiq sahi RTO code select karein. Lahore ke liye RTO-II Lahore ya RTO-I Lahore (depending on area). Agar confused hain — ek baar consultant se confirm kar lein.
5
Business Address Verify Nahi Ho Raha
Business NTN ke liye FBR business address verify karta hai. Agar address vague hai ("near main market"), ya zyada generic hai, ya FBR ke database se match nahi karta — rejection ya long delay hoti hai. Home-based freelancers ka residential address use karna mostly safe hai, lekin business address exactly enter karna zaroori hai.
Fix: Complete, specific address enter karein — street number, mohalla, city, tehsil, district. Agar home-based hain to residential address clearly enter karein as business address. Utility bill match karna helpful hota hai.
6
Email ID Already In Use
Ek email sirf ek NTN ke liye use ho sakti hai. Agar aapne pehle kisi aur ki application mein apni email daal di thi, ya khud pehle register kiya tha — same email se dobara nahi ho sakta. Gmail mein "+" trick bhi FBR accept nahi karta aksar.
Fix: Naya email address banayein (Gmail ya Yahoo) — apne registered email use na ho to is application ke liye fresh email use karein. Existing account recover karne ke liye FBR helpline contact karein.
7
Incomplete Form — Required Fields Khali
IRIS form mein kuch fields mandatory hain — bank account details, business activity, address. Inhe skip karne par form submit nahi hota ya "incomplete application" error aata hai. Kai log hurry mein required fields skip kar dete hain ya "Not Applicable" galat jagah select karte hain.
Fix: Form dobara carefully bharein. Bank account number, IBAN, business/employment type, aur address — sab zaroori fields properly fill karein. Incomplete submit se better hai time lagaye aur ek baar sahi karein.
8
CNIC Name vs Bank Account Name Mismatch
FBR bank account details bhi verify karta hai. Agar CNIC par naam "Muhammad Usman Ali" hai lekin bank account mein "M. Usman" hai — yeh mismatch flag ho sakta hai. Minor spelling differences bhi sometimes issue banti hain.
Fix: Bank mein naam update karwayein CNIC ke mutabiq, ya NTN registration mein exact same name enter karein jo bank record mein hai. Bank account title aur CNIC name exactly match karna best practice hai.

Rejection Notice Aya — Ab Kya Karein?

Agar FBR ne rejection notice bheja hai:

  • Notice mein specific reason padhein — FBR usually reason mention karta hai
  • Upar diye rejection reasons mein se apna issue identify karein
  • Fix complete karein (SIM biometrics, CNIC renewal, etc.)
  • Fresh application submit karein — ya existing application ka correction request karein
  • FBR helpline: 051-111-772-772 — ya email: helpline@fbr.gov.pk

Business address ya to vague tha, ya wrong RTO jurisdiction mein tha, ya FBR records se match nahi kiya. Complete, specific address use karein aur sahi RTO code select karein.

Haan, experienced consultant pehle se documents check karta hai — CNIC valid hai, mobile linked hai, address sahi hai, RTO code correct hai. Yeh pre-check rejection chances significantly reduce karta hai.
