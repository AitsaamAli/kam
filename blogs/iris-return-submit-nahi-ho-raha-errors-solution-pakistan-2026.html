IRIS Mein Return Submit Nahi Ho Raha — Common Errors Aur Unka Hal

September 2026 Kamboh Associates 10 min read
By Aitsaam Ali, Tax Consultant | NTN & Compliance Specialist

Poora return bhar lene ke baad jab submit button click karte hain aur portal ek error de deta hai, to yeh bohat frustrating tajurba hota hai — khaas tor par deadline ke qareeb. Yeh guide IRIS portal ki sab se aam technical errors, unki asal wajuhat, aur practical hal ka process dekhti hai.

TL;DR

IRIS submission errors aksar validation mismatch, session timeout, browser compatibility, ya PDF generation ki wajah se hoti hain — bohat kam hi asal "system down" hota hai. Zyadatar errors ko step-by-step troubleshoot kiya ja sakta hai. Deadline ke aakhri dinon mein server load ki wajah se bhi masail barh jate hain, is liye jaldi file karna hamesha behtar hai.

Validation Errors — Sab Se Aam Qism

IRIS portal submit karne se pehle apne aap kuch internal checks karta hai — misal ke tor par yeh dekhna ke total income figures wealth statement se match karte hain ya nahi, ya kisi mandatory field khali to nahi. Jab yeh checks fail hoti hain, portal ek validation error dikhata hai aur submission rok deta hai.

Yeh error asal mein aapke liye faida-mand hai — yeh aapko ghalti file hone se pehle bata deta hai. Practical hal yeh hai ke error message ko dhyan se parhen (yeh aksar bata deta hai kaunsa specific field ya section masla-dar hai), us section ko wapas khol kar check karein, aur figures ko match karayein.

Common wajah: return ka total income wealth statement ke reconciliation se match nahi karta — yeh sab se zyada aam validation error hai. Dono documents ko sath-sath khol kar cross-check karna faida-mand hota hai.

Ek doosri aam validation error yeh hoti hai jab kisi mandatory attachment (jaise wealth statement reconciliation ka koi hissa) khali chhoot jaye. Portal aksar exact field ka naam ya section number bata deta hai — us specific jagah wapas jayen bajaye poore form ko dobara scan karne ke.

Session Timeout Aur Data Loss

Agar aap lambe waqt tak IRIS par kaam karte rahen bila kuch save kiye, to system session timeout kar sakta hai — jis se already bhara hua data reset ho sakta hai. Yeh khaas tor par tab hota hai jab return complex ho aur bharne mein lamba waqt lage.

Har section complete karte hi "Save" karne ki aadat banayein, poora return ek hi baithak mein na bharen.
Agar session timeout ho jaye, dobara login kar ke check karein ke kitna data save hua tha, phir baqi complete karein.
Slow internet connection is masle ko aur barha deta hai — mumkin ho to stable connection istemal karein.

Browser Compatibility Ke Masail

IRIS portal kuch purane ya kam-istemal-shuda browsers ke sath acha kaam nahi karta. Agar buttons click nahi ho rahe, pages sahi load nahi ho rahe, ya form fields ghayab hain, to yeh aksar browser compatibility ka masla hota hai, IRIS ka bug nahi.

Ek updated, mainstream browser (jaise Chrome ka current version) istemal karein.
Browser cache aur cookies clear kar ke dobara try karein.
Agar ek browser mein masla ho, doosre browser mein try karein taake pata chale masla browser ka hai ya portal ka.

PDF Generation Fail Hona

Kabhi kabhi return submit ho jata hai lekin acknowledgement ya return ka PDF generate nahi hota, ya download button kaam nahi karta. Yeh aam tor par ek temporary server-side masla hota hai. Pehla qadam yeh hai ke IRIS mein login kar ke "Filed Returns" ya "Completed Tasks" section check karein — agar return waqai submit ho gaya hai, to woh wahan nazar aayega, chahe PDF abhi generate na hua ho.

Khabardar: agar aapko lage return submit nahi hua, dobara submit karne ki koshish se pehle poori tarah confirm kar len ke pehli koshish waqai fail hui thi — warna duplicate submission ka masla ban sakta hai.

Agar "Filed Returns" section mein bhi return nazar nahi aa raha aur aapko yaqeen hai ke submit button click hua tha, to ek chhota intezar (kuch ghantay) kar ke dobara check karein — kabhi kabhi backend processing mein waqt lag jata hai. Agar us ke baad bhi kuch nazar na aaye, tab dobara try karna theek hai.

CNIC/NTN Mismatch Errors

Agar aapka CNIC recently update hua hai (naya CNIC number, ya expiry renewal), ya aapki NTN profile ki koi detail purani hai, to system mismatch error de sakta hai. Is soorat mein pehle IRIS profile mein detail update karani hoti hai, phir return submission try karein.

Aisi Errors Se Bachne Ke Practical Tips

Zyada tar IRIS errors ko pehle se hi bacha ja sakta hai:

Return banana shuru karne se pehle CNIC expiry aur NASRA/NTN profile ki detail ek dafa check kar len.
Wealth statement aur return dono ko sath-sath tayyar rakhein, taake final submission se pehle figures already match kar rahe hon.
Deadline se kam az kam ek hafta pehle try karein, taake agar koi error aaye to usay theek karne ka waqt mile.
Documents pehle se compress kar ke tayyar rakhein, last-moment mein file size ka masla na aaye.

Deadline Ke Din Server Load Ka Masla

Filing deadline (30 September) ke aakhri kuch dinon mein, khaas tor par aakhri din, lakhon log ek sath IRIS istemal karte hain. Is waqt server slow ho sakta hai, pages load hone mein waqt lag sakta hai, aur submission mein delay ho sakta hai. Yeh IRIS ka koi permanent bug nahi — sirf high-traffic ka natural asar hai.

Isi liye deadline se kaafi pehle file karna behtareen strategy hai — na sirf jurmane se bachne ke liye, balke technical masail ka risk kam karne ke liye bhi.

Attachment Aur File Size Errors

Agar aapko koi document (jaise salary certificate ya bank statement) attach karna hai aur portal usay reject kar raha hai, to aam wajah file ka size ya format hoti hai. IRIS aam tor par chhoti PDF files behtar accept karta hai — bari, high-resolution scan files kabhi kabhi upload nahi hoti. Document ko compress kar ke ya lower-resolution scan bana kar dobara try karein.

Galat Tax Year Select Ho Jana

Ek aam, lekin khatarnak, ghalti yeh hai ke form khulte waqt galat tax year select ho jata hai aur aap us mein poori mehnat se data bhar dete hain. IRIS is ghalti ko hamesha foran nahi pakarta, is liye submit karne se pehle hamesha screen ke upar dikhne wala tax year dobara check karein — yeh sab se zyada waqt bachane wali aadat hai.

Kab FBR Helpline Aur Kab Consultant Se Rabta Karein

Agar masla portal-wide hai (yani bohat se log ek jaisi error report kar rahe hain us waqt), to FBR helpline ya official channels se pata chal sakta hai ke system-wide issue hai aur kitni der mein theek hoga. Lekin agar masla aapke specific data ya calculation se juda hai — jaise validation error jo wealth statement mismatch bata rahi ho — to woh sirf aapka apna case hai aur wahan ek tax consultant zyada seedha hal de sakta hai.

Frequently Asked Questions

IRIS par submit karte waqt validation error aa rahi hai — matlab kya hai?
Yeh aam tor par matlab hota hai ke aapke return ke figures wealth statement se match nahi kar rahe, ya koi mandatory field khali hai. Error message dhyan se parhen — woh aksar specific section bata deta hai.
Session timeout ho gaya aur mera data chala gaya — kya karoon?
Dobara login kar ke check karein ke kitna data save hua tha, phir baqi hissa complete karein. Aage se har section complete karte hi save karne ki aadat banayein.
Return submit ho gaya lekin PDF download nahi ho raha — kya karoon?
Pehle IRIS mein "Filed Returns" section check karein ke return waqai submit hua hai ya nahi. Agar submit ho gaya hai to PDF ka masla temporary server issue ho sakta hai — dobara submit na karein.
Deadline ke aakhri din IRIS bohat slow hai — kya karoon?
Yeh high-traffic ka natural asar hai, IRIS ka bug nahi. Behtareen tareeqa yeh hai ke deadline se kaafi pehle file karein taake yeh masla mahsoos hi na ho.
Meri specific error kisi ko doosron ko nahi aa rahi — kya karoon?
Agar masla sirf aapke data se related hai (jaise validation mismatch), to ek tax consultant se rabta karna FBR helpline se zyada seedha hal dega, kyunke woh aapka exact case dekh sakta hai.
Document attach nahi ho raha — kya masla hai?
Aam wajah file ka size ya format hoti hai. Bari, high-resolution scan files kabhi kabhi reject ho jati hain. Document compress kar ke ya lower-resolution scan bana kar dobara try karein.
Galat tax year mein data bhar diya — kya IRIS khud pakar leta hai?
Hamesha nahi. Yeh ek aam ghalti hai jo IRIS foran nahi pakarti. Submit karne se pehle hamesha screen ke upar dikhne wala tax year dobara check karein — yeh sab se zyada waqt bachane wali aadat hai.
Ek mandatory field khali reh gayi thi lekin error message samajh nahi aaya — kya karoon?
Error message ko dhyan se dobara parhen — yeh aksar specific field ya section number bata deta hai. Agar phir bhi samajh na aaye, screenshot le kar ek tax consultant ko bhej dein, woh foran identify kar leta hai kaunsa hissa masla-dar hai.
Filed Returns section mein bhi return nazar nahi aa raha — dobara submit kar dein?
Pehle kuch ghantay intezar kar ke dobara check karein, kyunke backend processing mein kabhi kabhi waqt lag jata hai. Sirf us ke baad bhi kuch na dikhe to dobara submit karna theek hai.
Mobile phone se IRIS istemal kar sakte hain?
Technical tor par mumkin hai lekin recommend nahi kiya jata. IRIS ka layout desktop/laptop ke liye behtar optimize hai, aur mobile browser par validation errors aur session issues zyada aam hote hain.
IRIS ka error kis language mein aata hai — Urdu ya English?
Zyada tar error messages English mein aate hain. Agar samajhne mein masla ho, message ka screenshot le kar consultant ko bhej dein — woh foran tarjuma kar ke sahi hal bata dega.
Kya IRIS errors sirf return filing mein aati hain ya wealth statement mein bhi?
Dono jagah aa sakti hain, kyunke wealth statement bhi usi portal ka hissa hai. Zyada tar principles wahi hain — error message parhein, specific section check karein, aur zaroorat ho to consultant se rabta karein.
