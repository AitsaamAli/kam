Filer vs Non-Filer Pakistan 2026 — WHT Rates, Tax Benefits aur Filer Kaise Banein

July 15, 2026Aitsaam Ali10 min readBudget 2026-27 Updated

Pakistan mein "filer" aur "non-filer" ka farq ek simple tax return se kahin zyada hai — ye farq har property deal, bank profit, vehicle purchase, aur dividend par hazaron rupay bachane ya gawane ka farq hai. FBR ne Budget 2026-27 mein non-filers par mazeed restrictions lagayi hain. Ye guide aapko batayegi ke exactly kitna farq hai — aur aaj hi filer kaise banein.

Filer aur Non-Filer — Basic Farq

Filer: Woh shakhs jo FBR Active Taxpayer List (ATL) mein registered ho — yaani jo tax return file karta hai aur FBR database mein active hai.
Non-Filer: Woh shakhs jis ne tax return file nahi ki — ATL mein naam nahi — FBR ke nazdeek "inactive taxpayer".

Filer status ka fayda milta hai withholding tax (WHT) rates mein — filer par rates non-filer se significantly kam hoti hain. Ye rates government ne qanoon mein fix ki hui hain — koi discretion nahi, har transaction par automatically apply hoti hain.

ATL check karo: atl.fbr.gov.pk par apna CNIC enter karo — agar naam hai tou filer ho, nahi hai tou non-filer. Status real-time update hota hai return file karne ke 24–72 ghante baad.

Non-Filer Par Budget 2026-27 Ki Nayi Restrictions

FBR ne Budget 2026-27 mein non-filers par mazeed sakht pabandiyan lagayi hain:

  • Property purchase limit: Non-filer Rs 5 crore se zyada ki property nahi khareed sakta — registered nahi hogi
  • Vehicle restriction: Non-filer 1300cc se zyada ka naya vehicle nahi khareed sakta (directly registered nahi)
  • Import business: Non-filer import license/LC nahi le sakta
  • Bank cash withdrawal: Rs 50,000/day se zyada par 0.6% WHT — sirf non-filer par
  • FBR data sharing: Banks, NADRA, FBR ab data share karte hain — non-filer expose ho jata hai

FBR tracking: FBR ab NADRA, Punjab Land Record, State Life, banks sab se data le raha hai. Non-filers ke transactions track ho rahe hain — kisi bhi waqt notice aa sakta hai. Pehle file karo, notice ane se pehle.

Kise Filer Banna Chahiye?

  • Property owner ya dealer: Har deal mein lakhs bachate hain — filer banna pehla kaam hai
  • Salaried employee: Employer WHT kaat leta hai — filer hona chahiye refund ke liye bhi

Business Owner Ke Liye Filer Status — Kyun Double Zaruri Hai

Salary wale log sochte hain ke filer hona optional hai — lekin business owners ke liye toh absolutely mandatory hai. ATL Status Kho Jana — Kab Hota Hai Aur Kaise Bachein

Filer status ek baar banna — hamesha ke liye filer nahi. Har saal nayi return file karni padti hai warna ATL se naam hat jaata hai. FBR saal mein ek baar September mein ATL update karta hai — jo logon ne 30 September deadline tak return file nahi ki, unka naam hat jaata hai aur non-filer rates laag ho jaati hain.

  • ATL update date: September 30 — deadline ke baad file ki to agla saal September tak non-filer
  • Agar naam hat jaye: Ek poore saal ki transactions par double WHT — lakhs ka nuksaan
  • Late return: Rs 1,000 penalty lagti hai — lekin file karo zaroor, status wapas milta hai
  • ATL check: atl.fbr.gov.pk par CNIC enter karo — real-time status pata chalta hai
  • Solution: August se pehle return file karo — September rush mein delay nahi

Joint Property Ownership Mein Filer Status Kaise Kaam Karta Hai

Bohat se properties Pakistan mein joint names par hoti hain — husband-wife, father-son, ya siblings. WHT calculation is case mein har co-owner ke apne filer status ke hisab se alag hoti hai:

  • Agar do co-owners mein se ek filer hai aur doosra non-filer — WHT unke ownership share ke hisab se split hoti hai, har share par apni respective rate lagti hai
  • Registry authority (sub-registrar) dono owners ka CNIC verify karta hai ATL se — mixed-status deals mein calculation zyada complex hoti hai
  • Best practice: property deal se pehle dono co-owners ko filer banwa lein — is se calculation simple ho jaati hai aur maximum savings milti hain

Family tip: Agar family mein ek property multiple heirs ke naam hai (inheritance ke baad), sab heirs ko filer banwana ek dafa ka kaam hai jo future mein har transaction par bachat deta hai — chahe abhi property bechne ka irada na bhi ho.

Non-Resident Pakistanis (NRPs) ke liye filer status ka matlab thora different hai. Non-resident hone ke bawajood, agar Pakistan mein income hai — rental, bank profit, ya property — filer status utni hi zaroori hai jitni resident ke liye:

NTN Se ATL Tak — Common Delays Aur Kaise Bachein

Bohat se log NTN bana lete hain aur return bhi file kar dete hain, phir bhi ATL mein naam der se ya bilkul nahi aata. Sabse common reasons ye hain:

  • Return "draft" mein hi reh gayi: Bohat se log form fill kar ke "submit" button dabana bhool jaate hain — sirf save karne se ATL update nahi hota, poori submission zaroori hai
  • Mobile number ya email NADRA record se match nahi karta: IRIS verification fail ho sakti hai agar registered mobile/CNIC details purani hain
  • Wealth statement missing: Return submit ho gayi lekin wealth statement incomplete hai — is case mein return "defective" mark hoti hai aur ATL update nahi hota jab tak fix na ho
  • Peak season delay: September mein lakhs log ek sath file karte hain — IRIS system slow ho jaata hai aur ATL update mein normal 24-72 ghante ki jagah ek hafta lag sakta hai

Solution: Return submit karne ke turant baad acknowledgment receipt download karo aur usme "status: submitted" confirm karo — sirf "saved" nahi. Agar 3 din baad bhi ATL mein naam nahi aaya, IRIS helpline (051 111 772 772) par acknowledgment number ke sath contact karo.
