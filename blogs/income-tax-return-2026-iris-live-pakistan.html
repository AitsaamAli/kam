IRIS 2.0 Par Return Kaise Karein — Step-by-Step

IRIS 2.0 Par Login Karein

iris.fbr.gov.pk par jao. CNIC (without dashes) aur password se login karo. Pehli baar hai? "Registration" se NTN banao — ya Kamboh Associates se same-day NTN service lo.

Return Form Open Karein

Dashboard mein "Income Tax" section mein jao → "Return of Income" → "Income Tax Return" → Tax Year 2026 select karo. Return form open ho jayega.

Personal Information Verify Karein

Name, CNIC, address, taxpayer type (salaried / business / AOP) check karo. Employment details — employer NTN, salary amount enter karo.

Income Declare Karein

Salary income (Section 149 withheld tax bhi), business income, rental income, bank profit, capital gains — jo bhi applicable ho sab enter karo. Exempt income alag column mein.

Wealth Statement Fill Karein

Assets declare karo: property (FBR value), vehicle, bank balance (30 June 2026), cash, gold, business capital. Liabilities: loans, mortgages. Opening + closing reconcile hona chahiye.

Tax Credits Check Karein

Withheld tax credits (employer, bank, buyer ne kata), advance tax payments, tax credits (charity, education fee, insurance) enter karo. System net payable ya refundable calculate karega.

Draft Save Karein (Abhi Submission Pending)

Sab data enter karne ke baad "Save Draft" karo. FBR jab submission enable kare — aao aur final submit kar do. Submission se pehle ek baar professional se review karwana behtar hai.

Common Mistakes jinse bachein: Wealth statement mein property ki value galat likhna (DC rate ya FBR value use karna chahiye), bank accounts skip karna, spouse ya bachon ki assets apni wealth mein include na karna, foreign income declare na karna — in sab se FBR notice aa sakta hai.

Refund Kaise Milega — Agar Zyada Tax Kat Gaya

Bohot se log yeh nahi jaantay ke sirf return file karne se refund automatically nahi milta — ek alag refund application submit karni parti hai IRIS par, tabhi processing shuru hoti hai. Agar aapki salary se, bank profit se, ya property transaction se withheld tax aapki actual liability se zyada hai, toh yeh farq aapko wapas mil sakta hai.

Return File Karke Refund Amount Confirm Karo

Return submit hone ke baad system automatically calculate karega ke aapka refund due hai ya nahi — yeh sirf ek calculation hai, payment nahi.

Alag Se Refund Application Lagao

IRIS par "Refund" section mein ja kar separate application submit karo — is step ke baghair FBR paisay wapas nahi bhejta, chahay return mein refund dikh raha ho.

Bank Account Verify Karo

IRIS mein linked bank account apne naam ka aur active hona chahiye — galat ya purana account refund process ko rok deta hai.

Yaad Rakhein: Refund application na lagana sabse common mistake hai — log return file kar dete hain, refund dikhta hai, phir kabhi follow-up nahi karte aur paisa saalon tak unclaimed reh jaata hai.
