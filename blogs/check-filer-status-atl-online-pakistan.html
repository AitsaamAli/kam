Filer Status Check Online Pakistan 2026 — ATL List Mein Naam Kaise Dekhein

July 22, 2026Aitsaam Ali6 min read2 Minute Check

Property khareedni ho, bank se paisay nikalne hon, ya visa ke liye documents tayyar karne hon — sab jagah ek sawal poocha jata hai: "aap filer hain ya nahi?" Apna Active Taxpayer List (ATL) status check karna sirf 2 minute ka kaam hai — online website se ya SMS se. Is guide mein dono tareeqay step-by-step dekhtay hain.

TL;DR

ATL status online check karo fbr.gov.pk par CNIC/NTN se, ya SMS bhejo "ATL CNIC" 9966 par. List weekly update hoti hai. Naam missing ho toh return check karo ya surcharge pending ho sakta hai.

Filer Status Kyun Check Karna Zaroori Hai

ATL status seedha aapki jeb par asar dalta hai — filer hone se property, bank profit, vehicle, aur dozens transactions par withholding tax half ya usse bhi kam ho jati hai non-filer ke muqablay mein. Ye status check karna zaroori hota hai:

  • Property khareedne/bechne se pehle — WHT rate confirm karne ke liye
  • Bank se transaction karte waqt — cash withdrawal WHT ke liye
  • Visa application se pehle — kai countries FBR filer status maangti hain
  • Job / business dealings mein — client ya employer kabhi kabhi filer status verify karte hain
  • Confirm karne ke liye ke apna return successfully processed hua ya nahi

Online Website Se ATL Check Karein

FBR Website Kholein

fbr.gov.pk par jaayein — "Online Services" ya "Search Taxpayer" section dhoondein.

Active Taxpayer List (ATL) Select Karein

Individual ke liye "ATL (Income Tax)" option choose karein.

CNIC ya NTN Enter Karein

Apna 13-digit CNIC (bina dashes) ya NTN number daalein aur captcha verify karein.

Result Dekhein

System turant bata dega ke naam active list mein hai ya nahi, aur konse tax year ke record ke sath.

SMS Se ATL Check Karein — Sabse Tez Tareeqa

SMS Format: Apne mobile se type karein "ATL" (space) apna CNIC number bina dashes ke, aur bhej dein 9966 par. Kuch second mein reply mil jayega jo filer status confirm karega.

ATL Kitni Baar Update Hoti Hai

Active Taxpayer List weekly update hoti hai. Return file karne ke baad naya naam agli weekly cycle mein list mein shamil hota hai — usually 1 se 7 din ke andar. Deadline ke baad late filers ko surcharge pay karna padta hai ATL mein aane ke liye — surcharge clear hote hi naam add ho jata hai.

Naam missing hai toh pehle ye check karein: Return acknowledgment number confirm karo ke submission successful thi. Late filing surcharge pending toh nahi. Agar sab theek hai phir bhi naam nahi aa raha, FBR helpline 051 111 772 772 par confirm karein ya professional se madad lein.

Aksar Puchhe Gaye Sawal — Filer Status Check

Filer status online kaise check karein Pakistan mein?
FBR website (fbr.gov.pk) par jaake "Active Taxpayer List (ATL)" search option mein apna CNIC ya NTN daal kar search karein. Result turant dikhata hai ke naam ATL mein hai ya nahi, aur kis tax year ke liye active hai.
SMS se filer status kaise check hota hai?
Apne mobile se "ATL" (space) apna CNIC number bina dashes ke likh kar 9966 par SMS bhejein. Kuch second mein reply aayega jo bataega ke aap filer hain ya non-filer, aur konse tax year ke liye.
Return file karne ke kitne din baad naam ATL mein aata hai?
ATL list weekly update hoti hai — return file karne ke baad agli weekly update cycle mein naam list mein add ho jata hai, usually 1 se 7 din ke andar. Agar zyada der ho jaye toh return acknowledgment receipt check karo ke submission successful hui thi ya nahi.
Return file ki lekin naam ATL mein nahi aa raha — kya karein?
Pehle confirm karo ke return successfully submit hui thi (acknowledgment number check karo). Agar submission theek thi lekin naam phir bhi missing hai, ho sakta hai late filer surcharge pending ho — is case mein surcharge pay karne ke baad hi naam agli update mein aayega. FBR helpline 051 111 772 772 par bhi confirm kar saktay hain.
