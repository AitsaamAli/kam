🇮🇹 Italy Jane Se Pehle FBR Tax Return, NTN aur Wealth Statement — Pakistan 2026 Guide

July 15, 2026Aitsaam Ali9 min readSchengen Verified

Pakistan mein sabse zyada log Italy jane ke liye FBR documents ka masla face karte hain — Italian consulate ki Schengen visa application mein financial proof mandatory hai aur Pakistan mein ye proof FBR tax return ke zariye di jaati hai. Chahe family visa ho, work permit ho, ya long-stay visa — NTN aur returns without ke visa reject hone ki probability bahut zyada hai. Ye guide sirf Italy ke liye hai — specific documents, specific process, specific timeline.

Italy Consulate FBR Documents Kyun Maangta Hai

Italian consulate (Islamabad ya Karachi) Schengen visa application mein applicant ki financial sufficiency verify karta hai — ke aap Italy mein reh kar khud ka kharcha uthaa sakte hain. Pakistan mein formal income prove karne ka sabse credible zariya FBR ke saath registered hona aur return file karna hai.

Non-filer ya jis ka NTN nahi — us ke paas verifiable income ka koi government-endorsed record nahi hota. Consulate ke liye ye ek red flag hai. Italy mein pehle se 120,000+ Pakistanis hain — consulate ko pata hai ke Pakistani applicants ki financial documents assess karna zaruri hai.

Ye Italy-specific hai: Italy ka consulate Schengen rules follow karta hai lekin apne discretion ke saath documents assess karta hai. Tax returns sirf income proof nahi — ye stable economic activity ka sign hain jo long-stay aur family visas mein especially important hota hai.

Kya Karna Hai — Step by Step

Step 1 — NTN Check Karo: IRIS par login karo (iris.fbr.gov.pk) — agar account hai toh NTN already hoga. Nahi hai toh pehle register karo — 1–2 working days.

Step 2 — Returns Ki Status Check Karo: IRIS mein Declaration → Return of Income — dekho kitne saal ki filing pending hai. Italy ke liye TY 2024, 2025, 2026 priority hai.

Step 3 — Pending Returns File Karo: Har saal ki return + wealth statement file karo. Salary wale logon ke liye ye straightforward hota hai. Pending Returns Complete Guide dekhein.

Step 4 — ATL Confirm Karo: Filing ke 2–3 days mein ATL update hota hai. Text: 9966 par ACTIVE [CNIC] — confirmation aata hai. Ye print karo.

Step 5 — Documents Prepare Karo: IRIS se NTN certificate download karo, returns ki acknowledgment print karo, wealth statement ki copy lao — ye sab Italy consulate application mein jama karo.

Italy Mein Jaane Ke Baad Pakistan Tax Status

Italy settle hone ke baad aap ka Pakistan tax status automatically change hota hai — lekin time lagta hai:

  • Non-resident ban'ne ki condition: Us tax year mein Pakistan mein 182 din se kam rehna (July 1 – June 30)
  • Non-resident hone ke baad: Italy se kamai Pakistan mein taxable nahi — sirf Pakistan-source income (property rent, savings interest) taxable
  • Return file karna: Non-resident banne ke baad bhi Pakistan mein return file karna legal requirement hai
  • Italy mein tax: Italy mein resident hone ke baad worldwide income Italy mein taxable — Italian IRPEF rates (23%–43%) apply hote hain

Frequently Asked Questions — Italy FBR

Italy visa ke liye Pakistan mein tax return zaruri hai?
Haan. Italian consulate Schengen visa ke liye financial stability proof maangta hai — Pakistan mein ye FBR tax return se prove hoti hai. NTN, last 3 saal ki returns, wealth statement, ATL confirmation — ye standard documentation hai. Return nahi hai toh rejection risk high hai.
Italy family visa ke liye Pakistan mein kiski return chahiye?
Applicant ki return (jo Pakistan mein hai aur Italy ja raha hai). Plus Italy mein sponsor (family member) ki Italy tax return (730 ya Modello Redditi) bhi required hoti hai. Dono ka combination consulate financial stability assess karne ke liye use karta hai.
Italy mein kaam karte waqt Pakistan mein tax dena hoga?
Nahi — agar aap us tax year mein Pakistan mein 182 din se kam rahe hain toh non-resident hain aur Italy se kamai Pakistan mein taxable nahi. Sirf Pakistan-source income (property, savings) taxable rahegi. Lekin return file karna recommended hai.
NTN nahi hai — Italy visa apply ho sakta hai?
Technically apply ho sakta hai — lekin financial proof incomplete hogi. Consulate return file karne wale logon ko prefer karta hai. NTN 1–2 days mein banega aur phir returns file ho sakti hain. Kamboh Associates ye urgently complete karta hai.

Italy Schengen visa reject ho sakta hai sirf FBR return nahi hone ki wajah se?
Haan, ye ek valid rejection reason hai — "insufficient financial proof." Schengen visa ke liye financial adequacy mandatory assessment criterion hai. Pakistani applicants ke liye tax return sabse strong financial proof hai. Return ke bina bank statement bhi less convincing hoti hai.
