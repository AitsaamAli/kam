Section 114 — Return Filing Notice (Sabse Common)

Ye sabse aam notice hai — FBR ka matlab hai: "aap ne return file nahi ki, file karo."

  • Kaun ko aata hai: Jis ne kabhi return file nahi ki ya kuch saal miss kiye
  • Jawab: Return file karo — bus. Notice mein jo saal mention hain un sab ki returns IRIS par file karo
  • Deadline: Notice mein date likhi hai — typically 21–30 din
  • Penalty agar late: Rs 1,000/month ya 0.1% of tax — whichever higher
  • IRIS par response: Return file karne ke baad IRIS mein notice ka response submit karo (acknowledgment attach karo)

Section 114 notice aaya hai tou khud bhi file kar sakte hain IRIS par — ya Kamboh Associates se Rs 3,500/year mein karwayein. Zyada mushkil nahi — deadline se pehle karo.

Section 111 — Unexplained Income Notice (Serious)

Section 111 serious notice hai — iska matlab hai FBR ke paas information hai ke aapki declared income se zyada transactions/assets hain:

  • Bank deposits: Bank ne FBR ko report kiya ke aapke account mein zyada paisa aaya
  • Property purchase: Property registrar ne property sale/purchase report ki jo return mein nahi
  • Foreign remittances: State Bank ne remittances report ki jo return mein nahi
  • NADRA data: Lifestyle data — cars, travel, house — income se mismatch

Tax imposed: Explain nahi ki gai amount par 35% tax + 10% penalty + default surcharge. Proof of source sufficient ho tou tax nahi lagta.

Section 111 Ka Jawab — Kya Karna Hoga

  • Notice carefully parho — kaunsa specific year, kaunsi amount FBR ne highlight ki
  • Bank statements, property documents, remittance slips — sab gather karo
  • Agar amount inherited hai: Inheritance hoti raqam ka proof (wasiyyat, family settlement)
  • Agar agricultural income: Agricultural income exemption — revenue record + crop documents
  • Agar gift: Donor ki capacity prove karo (donor ki FBR returns + bank statements)
  • Written explanation letter tayyar karo — IRIS par submit karo + officer ko send karo

Section 111 par consultant zaruri hai. Galat jawab case bigaar sakta hai — jo explain nahi hua wo 35% par taxable hoga. Kamboh Associates Section 111 response specialist hai — WhatsApp karo: 0328-4675162

Section 177 — Audit Notice

Section 177 mein FBR aapke 3 saal ke records audit karta hai:

  • Documents maange jaate hain: All bank statements, all business records, purchase/sale invoices, property documents, salary certificates, wealth statements
  • Timeline: 180 din mein audit complete hona chahiye
  • Audit officer: FBR tax circle ka officer visit kar sakta hai ya documents office mein submit karne hote hain
  • Common triggers: Large cash transactions, sudden wealth increase, return discrepancies, third-party reports

Audit notice mein delay mat karo — proactively documents organize karo. Missing documents = red flag = higher demand.

Extension — Kaise Maangein

  • Deadline se pehle written request bhejni hoti hai — deadline ke baad request nahi milti
  • Reason clear karo: documents gather ho rahe hain, hospital mein tha, out of city, etc.
  • Officer ki discretion — audit/document notices mein zyada milti hai, return filing mein kam
  • Extension letter IRIS par bhi submit karo + officer ke office address par registered post

Appeal — Agar Assessment Galat Lagey

  • Commissioner Appeals (CIR-A): Section 127 — 30 din mein appeal, assessment order ke baad
  • Appellate Tribunal (ATIR): Section 131 — CIR-A decision ke baad 60 din mein
  • High Court: Point of law par
  • FBR Alternate Dispute Resolution (ADR): Rs 5 lakh+ cases mein — quick settlement option

FBR Notice Mein Common Galtiyan — Jo Bilkul Mat Karo

  • Notice ignore karna: Sabse badi galti — ex-parte assessment automatic hoti hai deadline ke baad
  • Ghair-zaruri documents dena: Jo nahi manga woh mat dena — extra information officer ko naye points deti hai
  • Zubani jawab dena: Hamesha written — IRIS par submit + registered post — proof rakhna zaroori
  • Emotional hona: Notice threatening lagta hai — calmly respond karo, professionally
  • Ek aadhi baat acknowledge karna: Admission of income without full context — harm ho sakta hai
  • Consultant ke baghair Section 111 respond karna: Technical mistakes case bigaar sakti hain
  • Deadline ke baad extension maangna: Extension request deadline se pehle — baad mein reject hoti hai

FAQs — FBR Notice

FBR ne 5 saal purane transactions par notice bheja — kya valid hai?
Haan — Section 111 mein FBR 5 saal purane transactions par notice de sakta hai (limitation period 5 saal). Fraud ya concealment case mein 10 saal. Isliye 5 saal ki bank statements aur records hamesha rakho.
Meri income kam hai — FBR notice kyun aaya?
FBR sirf aapki income declaration nahi dekhta — aapke bank transactions, NADRA data, property records, vehicle data sab check karta hai. Agar lifestyle ya assets income se zyada lag rahe hain — notice aata hai. Solution: source properly declare karo — aur return file karo.
Notice mein demand Rs 50 lakh hai — kya sach mein dena hoga?
Ex-parte assessments aksar inflated hoti hain. Agar proper jawab diya — actual liability bahut kam ho sakti hai. Section 111 mein explanation accept ho jaaye tou zero tax. Appeal mein bhi demand kam hoti hai. Consultant se evaluate karwao pehle — pura amount mat bharain bina assessment ke.

FBR ne bank account attach kar liya — ab kya?
Bank attachment Recovery Order (Section 140) ke baad hoti hai — ye serious hai. Foran Commissioner Appeals mein stay application deni hogi. Attachment notice usually prior demand ka result hai — agar demand settled ho tou attachment release hoti hai. Emergency mein 0328-4675162 par abhi call karo.
