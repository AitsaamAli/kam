How to Become an Active Taxpayer in Pakistan 2026 — Complete FBR ATL Guide

Pakistan mein "Active Taxpayer" banana aaj ke daur mein sirf ek legal requirement nahi — yeh aapki financial life ka sabse zyada profitable decision hai. FBR ki Active Taxpayer List (ATL) mein aapka naam hone se har banking transaction, property deal, aur business contract par double tax se bachao milta hai. Is complete guide mein hum step-by-step batayenge ke active taxpayer kaise banein, ATL status kaise check karein, aur 2026 mein kya kya requirements hain.

Active Taxpayer Kya Hota Hai Pakistan Mein?

FBR (Federal Board of Revenue) ki official language mein ek "Active Taxpayer" woh registered person hai jis ne apna National Tax Number (NTN) liya ho aur FBR ke IRIS portal par annual income tax return file ki ho — aur jis ka naam FBR ki published Active Taxpayer List (ATL) mein shamil ho.

Yeh teen cheezein milkar aapko "Active Taxpayer" banati hain:

NTN Registration
FBR IRIS portal par registered hona zaroori hai
Income Tax Return Filing
Har saal FBR ko return submit karna hoga
ATL Mein Naam
FBR Active Taxpayer List par aapka naam visible ho
Annual Update
Har saal return file karna ATL status maintain karta hai

Important: Sirf NTN lene se aap active taxpayer nahi ban jaate. ATL mein naam aane ke liye income tax return file karna compulsory hai. NTN aur ATL — dono alag cheezein hain. Agar aap ne NTN liya lekin return file nahi ki, to aap non-filer hain.

FBR Active Taxpayer List (ATL) Kya Hai?

Active Taxpayer List (ATL) FBR ki officially published list hai jis mein un tamam logon ke CNIC numbers hote hain jinhon ne income tax return file ki ho. Yeh list FBR website par publicly available hoti hai aur har Monday ko update hoti hai.

ATL mein naam hone ka direct matlab hai ke banks, government agencies, property registrars, aur businesses aapko "filer" ki category mein treat karenge — aur aap par reduced withholding tax rates apply honge.

ATL mein naam na hone ki soorat mein (non-filer status) aapko har transaction par 2x se 4x zyada tax dena parta hai. FBR ne yeh gap deliberately rakha hai taake log voluntarily filer banein. Ek saal mein yeh difference lakhon rupees ka ho sakta hai.

Step-by-Step: Active Taxpayer Kaise Banein? 2026

Active taxpayer banna 2026 mein ek straightforward process hai. Yeh 4 steps hain:

01
NTN Registration — FBR IRIS Portal Par
iris.fbr.gov.pk par jayen aur "Registration for Unregistered Person" option select karein. Apna CNIC number darj karein — individual ke liye NTN aapka CNIC number hi hota hai. OTP verify karein aur basic information fill karein. NTN registration bilkul free of charge hai.
Individual NTN = CNIC Number — yaad rakhna asaan hai
02
IRIS Login Karein Aur Return Form Open Karein
NTN register hone ke baad IRIS portal mein login karein. Dashboard mein "Declaration" section mein jayen aur "Income Tax Return" select karein. Current tax year (2025–26) ki return select karein. Apni income category choose karein — salaried, business, ya other sources.
FY 2025–26 ki return deadline: September 30, 2026
03
Return Form Bharein — Salary, Assets, Tax Paid
Return form mein apni total annual income darj karein (salary, business income, property rent, etc.). Employer ki taraf se deducted tax aur bank se kati hui WHT ko bhi mention karein. Wealth statement mein apni property, vehicles, aur bank balance declare karein. Sab kuch accurately fill karein — koi missing entry FBR notice ka sabab ban sakti hai.
Agar confusion ho to Kamboh Associates se help lein — 0328-4675162
04
Return Submit Karein Aur ATL Verify Karein
Return submit karne ke baad acknowledgment number save karein — yeh proof hoga ke return file ho gayi. Return file hone ke 24 se 72 ghante ke andar aapka naam FBR ATL mein aa jata hai. SMS bhejein apna CNIC number 9966 par ya atl.fbr.gov.pk par verify karein.
"Active" response aaye to congratulations — aap officially filer hain!

Kise Active Taxpayer Hona Chahiye?

Pakistan mein har us shakhs ko NTN register karna aur return file karna chahiye jo:

Salaried Employees
Agar aapki annual salary Rs. 6,00,000 se zyada hai to return file karna legally zaroori hai. Aur agar salary is se kam bhi ho, to filer hone ke financial fayde phir bhi milte hain — property ya gaari khareedne par.
Business Owners & Shopkeepers
Koi bhi business ya trade activity karne wale ko NTN compulsory hai. Business receipts par withholding tax cut hoti hai — jo sirf active filer recover kar sakta hai through return filing.
Freelancers & Online Workers
Upwork, Fiverr, ya koi bhi platform se foreign income receive karne wale freelancers ke liye NTN aur return filing both recommended aur increasingly required hai. Foreign remittance par non-filer 4% vs filer 2% deta hai.
Property Owners & Investors
Agar aap property buy/sell karte hain ya kiraya income hai, to filer hona bohot zaroori hai. Property transactions par non-filer double WHT deta hai — Rs. 1 crore ki property par filer Rs. 3 lakh deta hai, non-filer Rs. 6 lakh.

Aksar Pooche Jane Wale Sawalat (FAQs)

Active taxpayer aur regular filer mein kya farq hai?
Dono essentially ek hi cheez hain. "Active taxpayer" FBR ki official ATL terminology hai, jabke "filer" aur "active filer" common usage hain. Jab aap return file karte hain aur ATL mein naam aa jata hai — tab aap active taxpayer bhi hain aur filer bhi. Jo ATL mein nahi hote unhe non-filer ya befiler kaha jata hai.
Kya ek baar filer banne ke baad hamesha active rehta hoon?
Nahi. Active taxpayer status maintain karne ke liye aapko har saal income tax return file karni hoti hai. Agar aap ek saal skip karein to aapka naam ATL se remove ho jata hai aur aap non-filer ban jaate hain — phir se double WHT rates apply honge. Is liye har saal September deadline se pehle return file karna zaroori hai.
Koi income nahi hai to kya return file karni padegi?
Haan, agar aap ke paas NTN hai aur aap ATL benefits chahte hain to "nil return" file karni padegi — yani zero income ki return. Yeh process bilkul simple hai. Aur yeh zaroori hai khas taur par un logon ke liye jis ke paas property, bank accounts, ya gaari hai — kyunke un transactions par WHT benefit sirf active filer ko milta hai.
Active taxpayer banne mein kitna time lagta hai?
Pura process — NTN registration se lekar ATL mein naam aane tak — normally 24 se 72 ghante ka kaam hai. Kamboh Associates ke sath yeh aur bhi fast ho jata hai kyunke hum experienced professionals hain aur IRIS portal errors se bachte hain. Aaj apply karein, kal active taxpayer ban jayen.

Active taxpayer na hone par exactly kitna nuksan hota hai per saal?
Yeh aapke transactions par depend karta hai.
